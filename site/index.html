快速上手

从下载到报告，四步

需要一根 16 GB 左右的 U 盘和一台 Windows 电脑（用来写盘、看报告）。

  1. 校验镜像

    下载 ISO 后比对 SHA256。full 和 mem 的校验值不一样，别混用。

  2. 制作 U 盘

    用 Rufus 写盘，分区类型选 GPT。点「开始」后必须选「DD 映像模式」；写完 Windows 提示格式化时点取消。

  3. 建报告分区

    在 U 盘剩余空间新建一个 exFAT 分区，卷标写 KLBURN（全大写），报告就存在这里。

  4. 开机，等报告

    BIOS 启动菜单选 U 盘，选好范围和时长后就可以离开。出现 PASS / FAIL 大字后拔盘，打开 .html 或 .pdf 报告。

注意：写盘会清空整根 U 盘。硬盘压测会擦除被测服务器的数据盘，所以要确认两次，默认跳过。

测试内容

六个阶段，压测之后还要复查

压测跑完不报错，不等于机器没问题，关键要看压测把什么问题逼了出来。

  1. 采集整机、CPU、逐条内存、硬盘（含阵列卡后的物理盘）、网卡、显卡、电源、BMC
  2. 核对同规格部件的型号与固件、内存容量、PCIe 降级、序列号。配置不一致判 WARN
  3. 基准CPU 浮点、内存带宽、硬盘读写、显卡带宽与互联。只报数，不判合格
  4. 专项CPU 计算正确性、SMART 自检、网卡自检、显卡厂商诊断
  5. 压测CPU / 内存 / 显卡并发跑满时长，硬盘单独跑
  6. 复查ECC、热节流、PCIe AER、内核日志、BMC 事件、SMART 增量，都按压测前后的差值判

整机版的六个范围

1
全量测试出厂验收用这个 · _Full
2
CPU换过 CPU、怀疑算错 · _CPU
3
内存换过内存、查 ECC · _MEM
4
显卡只验显卡 · _GPU
5
硬盘时长全给硬盘 · _DISK
6
仅导出报告几分钟出配置清单 · _INFO

单项范围的报告不能当整机验收依据，报告抬头会写明本轮范围。

判定原则

宁可说「没测」，也不乱判

四态判定

PASS / WARN / SKIP / FAIL。没装显卡、没接网线判 SKIP，装了却认不到才判 FAIL。一条判定都没有时，报告会写明本报告无效。

性能只报不判

代码里没有任何「参考值」。由做验收的人，用自己的标准去对实测数据。

不冤枉好机器

测试环境自己的问题（比如 OOM、驱动不支持新卡）判 WARN 或 SKIP，并写明原因。

阵列卡后面也查

自动识别 RAID 卡，逐块透传读物理盘的 SMART，避免「报告写 PASS，一块盘都没查」。

不会写坏启动盘

硬盘压测的目标盘要经过五道排除，Ventoy 场景按设备号反查；破坏性写入要确认两次。

报告一定落盘

报告分区有四层回退查找，都找不到时屏幕上会给黄色大框警告，不会悄悄丢报告。
