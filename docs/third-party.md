# 许可证与第三方分发边界

仓库根目录的 MIT 许可证只覆盖 KLBurn 自有原创代码与文档。
Ubuntu 系统、Linux 内核、固件、字体、运行库和第三方工具保留各自许可证与归属，
不能把整张 ISO 宣称为 MIT。

## 当前审查事实

本次公开前审查仍未完成，尚不能据此宣布现有 ISO 已满足公开再分发条件。
历史内部构建通过、哈希一致或工具可运行，均不构成分发权利证明。

| 组件类别 | 当前证据与限制 |
|---|---|
| Ubuntu、Linux、GNU 工具、memtest86+ 等 | 存在 GPL/LGPL 等组件；需按具体包版本保留许可证，并落实适用的对应源码提供方式。仅链接上游首页不是完整源码交付证明。 |
| 固件与 CPU 微码 | 许可随具体固件包而异，不能由内核 GPL 推断全部固件适用 GPL。 |
| OpenBLAS、字体、zlib、zstd | 保留对应许可证、版权及适用的再分发说明。静态或动态链接方式须按实际产物核对。 |
| NVIDIA 驱动和 CUDA 运行库 | 已从哈希核对一致的 595.84 安装包提取 Driver License Agreement（2025-02-25）。第 1.1(d) 条有条件允许用于开源内核的分发，要求不修改二进制并向接收者提供协议；另有硬件与用途限制。实际 ISO 条件符合性及 CUDA 运行库条款尚未全部核清，不能把 open 内核模块许可套用于全部组件。 |
| gpu-burn、cuda-samples、OpenDCDiag | 已取得 cuda-samples 固定源码版本的 BSD-3 文本，及 OpenDCDiag 固定版本的 Apache-2.0 与附带 MIT/BSD-3 声明；必须保留全部适用归属。gpu-burn 当前上游为 BSD-2，但现有二进制对应源码 commit 尚需核实。 |
| Intel LINPACK、MLC | 免费下载不等于无条件再分发；`redist.txt` 也不能替代其所引用的完整许可协议。 |
| Broadcom StorCLI 及其他厂商管理工具 | 须获得适用版本的分发依据；不能因为内部测试盘已有二进制就直接向公众发布。 |

审查发现现有 MLC 离线目录中一个以许可协议 PDF 命名的文件实际为旧版压缩包，
因此该文件不能作为当前版本的许可证明。保留原始证据，不将其改名冒充有效许可。

## 发布边界

- 不删除第三方版权声明、许可证或必要归属。
- 不把客户原始报告、私有测试样本、凭据或内部构建日志作为公共 Release 附件。
- 新版公开下载元数据只包含版本、tag、源码 commit、日期、文件名、大小、SHA256
  与公开资产 URL；内部 manifest 与失败记录保留在私有验收资料中。
- 历史 tag、历史源码与历史二进制也属于仓库可见性变更的审查范围。
- 尚未解决的具体许可或敏感资料问题不能通过勾选“检查通过”来消除。

这份文档记录技术审查边界，不替代权利人的授权或法律意见。
